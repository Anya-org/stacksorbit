# Repo ownership

## Purpose

`conxius-orbit` is a supporting developer tooling repo in the Conxian portfolio.

## This repo owns

- deployment tooling support
- contract deployment workflows
- supporting builder tooling around deployment and environment setup

## This repo does not own

- general platform orchestration
- canonical integration logic
- shared-core ownership
- strategic portfolio identity

## Boundary rule

This repo should remain tool-focused and deployment-focused rather than expanding into a general platform or integration repo.

## Strategic role

Supporting repo.
